\# Oasis Infobyte Internship Projects



This repository contains the Java projects completed as part of my Oasis Infobyte Internship Program.



\## Projects



\### Task 2 – Number Guessing Game



A Java-based number guessing game where the computer selects a random number between 1 and 100 and the player tries to guess it within a limited number of attempts.



\*\*Features:\*\*



\* Random number generation

\* Limited attempts

\* Higher/Lower hints

\* Multiple rounds

\* Attempt count

\* Play again option



\*\*Technology:\*\* Java



Project folder: `Java-Task2-NumberGuessingGame`



\---



\### Task 3 – ATM Interface



A Java-based ATM simulation that provides basic banking operations through a command-line interface.



\*\*Features:\*\*



\* User login with PIN

\* Withdraw money

\* Deposit money

\* Transfer money

\* Insufficient balance handling

\* Transaction history

\* Exit option



\*\*Technology:\*\* Java



Project folder: `ATM-Interface`

\## How to Run



Make sure Java is installed on your system.



\### Number Guessing Game



From the repository folder:



```bash

java Java-Task2-NumberGuessingGame\\NumberGuessingGame.java

```



\### ATM Interface



Compile the Java files inside the ATM project folder and run the main class:



```bash

cd ATM-Interface

javac \*.java

java main

```
