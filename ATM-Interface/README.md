\# ATM Interface



\## About the Project



The ATM Interface is a Java console-based application that simulates basic ATM and banking operations.



The application allows users to log in using a PIN and perform operations such as checking their balance, withdrawing money, depositing money, transferring money, and viewing transaction history.



\## Features



\* PIN-based user login

\* Multiple login attempts

\* Balance checking

\* Cash withdrawal

\* Insufficient balance handling

\* Money deposit

\* Transfer money to another account

\* Transaction history

\* Exit option



\## Technologies Used



\* Java

\* Object-Oriented Programming

\* Classes and Objects

\* Scanner for user input

\* Loops

\* Conditional statements

\* ArrayList / collections (if used in the project)



\## Project Structure



| File               | Purpose                                 |

| ------------------ | --------------------------------------- |

| `main.java`        | Starts the ATM application              |

| `ATM.java`         | Handles ATM operations and menu         |

| `Account.java`     | Manages account information and balance |

| `Bank.java`        | Manages bank/account-related operations |

| `Transaction.java` | Stores transaction information          |



\## How to Run



Make sure Java is installed on your system.



Open the ATM project folder:



```bash

cd ATM-Interface

```



Compile the Java files:



```bash

javac \*.java

```



Run the main class:



```bash

java main

```
