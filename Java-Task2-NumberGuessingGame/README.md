\# Number Guessing Game



\## About the Project



The Number Guessing Game is a simple Java console-based game where the computer generates a random number between 1 and 100.



The player has a limited number of attempts to guess the correct number. After each guess, the program gives a hint indicating whether the guess is too high or too low.



\## Features



\* Generates a random number between 1 and 100

\* Allows a maximum of 7 attempts per round

\* Provides "Too High" and "Too Low" hints

\* Displays the number of attempts taken

\* Supports multiple rounds

\* Allows the player to choose whether to play again

\* Displays a message when the correct number is guessed



\## Technologies Used



\* Java

\* Random number generation

\* Scanner for user input

\* Loops

\* Conditional statements



\## How to Run



Make sure Java is installed on your system.



From the project folder, run:



```bash

java NumberGuessingGame.java

```



\## How the Game Works



1\. The computer generates a random number between 1 and 100.

2\. The player enters a guess.

3\. The program compares the guess with the generated number.

4\. If the guess is higher, the program displays "Too High".

5\. If the guess is lower, the program displays "Too Low".

6\. If the guess is correct, the program displays the number of attempts taken.

7\. The player can choose to play another round or exit.
